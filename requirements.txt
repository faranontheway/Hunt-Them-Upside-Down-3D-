### Step 4: Initialize Git Repository

1. Click the **Source Control** icon in left sidebar (looks like a branch)
   - Or press `Ctrl+Shift+G`

2. You'll see **"Initialize Repository"** button
   - Click it

3. VS Code will ask which folder to initialize - select your project root folder

1. In **Source Control** panel, you'll see all your files listed under "Changes"

2. **Stage all files:**
   - Hover over "Changes" heading
   - Click the **"+"** icon that appears
   - Or click **"+"** next to each individual file
